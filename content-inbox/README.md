# Content inbox

Put photos, videos and notes here for importing into the archive. Everything in this folder
except this README is ignored by git, so nothing personal is pushed to GitHub.

Everything is imported as an unpublished draft. Nothing appears on the site until a curator
publishes it in the dashboard.

## What to put here

- **`photos/`**: photos and short videos (JPG, PNG, HEIC, WebP, MP4, MOV; up to 50 MB each).
  Any file names are fine, but simple names make the notes easier (`first-birthday.jpg`).
- **`notes.md`**: anything you know about the photos and the moments in Roni's life.
  Copy `notes-template.md` to `notes.md` and fill in what you can. Leave anything you don't
  know blank: nothing is invented, so only what you write will be used.
